# Instant Fishing Salvage

Instant Fishing Salvage keeps Palworld's normal hold-to-interact and player
animation, skips the fishing salvage minigame, and reports a successful result
through Palworld's vanilla salvage UI model.

Palworld still performs the reward roll, fishing-passive adjustments,
inventory grant, and salvage-spot cleanup. The mod does not create or modify
reward items itself.

This is a client-side UE4SS Lua mod. Install it for every player who wants
automatic salvage completion.

The current package is development build `0.1.0-dev.18`; runtime diagnostics
and loader debug mode are enabled.
