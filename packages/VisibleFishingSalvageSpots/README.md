# Visible Fishing Salvage Spots

A Palworld 1.0 client-side visual mod intended to make fishing salvage spots
easier to notice from a distance and against visually busy water.

## Features

- Add a clear visual cue to active fishing salvage spots.
- Prefer a brighter emissive effect, stronger contrast, or a vertical marker.
- Avoid changing spawn rates, rewards, interaction distance, or save data.
- Ship as a lightweight Paks mod unless investigation shows the visual is
  created dynamically and requires a runtime hook.

## Production release

The Workshop-ready production build is:

`package/VisibleFishingSalvageSpots/Paks/VisibleFishingSalvageSpots_1.1.0_P.pak`

It gives normal and Rank 2 salvage spots Palworld's original, unmodified
`NS_Dungeon_Gate_In_WorldTree` marker, plus stronger emissive salvage
materials. The mod packages no cloned or modified Niagara system.
